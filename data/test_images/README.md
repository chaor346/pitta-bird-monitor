# test_images/ 图像测试集（精选子集）

> **⚠️ 这里的 145 张图片是从完整数据集里挑选的"演示子集"，全部来自训练池（模型训练时见过），只用于展示功能，不能用来对外报泛化指标。**
> 完整数据集：`raw_pitta` 1,302 张正样本 + `neg` 380 张负样本（321 其他鸟 + 59 纯背景），训练/验证划分为 `images/train` 1,643 张、`images/val` 260 张（其中 221 张与训练集字节相同），原始池合计 **1,682 张**；因体积过大（约 600MB）未随提交包提供。评审可据此快速验证模型功能；如需完整数据集或复现完整训练，请联系作者。
> 指标请引用 `eval_val/`：训练池有标注 1,061 张检出 99.2%、mAP@0.5 86.7%（训练池口径）；独立测试见 `independent/`（266 张网络公开图，图像级召回 96.2%）。

## 图片来源与筛选方法

- **正样本**：来自网络公开的仙八色鸫照片（raw_pitta，约 500×333），都是训练集用过的图。用 PC 端模型 `best.onnx`（YOLOv8n，320×320，conf=0.52、letterbox）批量标注，2026-10-25 复算：1,302 张里检出 1,090 张（83.7%）；只在**有标注的 1,061 张**上算，检出 1,052 张（99.2%）、框位正确（IoU≥0.5）1,046 张（98.6%）。为让近/中/远有**明显视觉差别**，按框面积取三档：close ≥50%、medium 20%–30%、far 3%–8%，各取置信度最高的 20 张；raw 补充 30 张中小距离（框面积 12%–20%）。
- **纯背景负样本**：训练集 images/train 中的 `neg_*.jpg` 森林背景（全量 59 张，本目录取 20 张）。
- **其他鸟类负样本**：训练集 neg 目录中的 `negbird_*.jpg`，为与仙八色鸫共享生境的常见鸟（麻雀、鹎、鸫、绣眼、鹊鸲、钩嘴鹛、红耳鹎、蜡嘴雀、北红尾鸲等）。全量 380 张负样本（321 其他鸟 + 59 背景）2026-10-25 复算 **0 误报、最高分 0.0**；逐张确认含鸟后精选 30 张。
- **板端推理画面（`board_captured/`，5 张）**：拍摄自推理输出终端屏幕（PYNQ-Z2 跑模型后由显示器输出），画面里带绿框与 `fairy_pitta` 标签，鸟种全部为仙八色鸫。

  | 文件 | 画面内容 | 屏幕标签 |
  |------|----------|----------|
  | `board_01.png` | 单鸟，鸟占画面主体 | fairy_pitta 0.93 |
  | `board_02.png` | 单鸟，含岩石与林地背景 | fairy_pitta 0.93 |
  | `board_03.png` | 单鸟，底部带预览工具栏（源图 500×279） | fairy_pitta 0.93 |
  | `board_04.png` | 单鸟，构图最满 | fairy_pitta 0.95 |
  | `board_05.png` | 双鸟同框，两个框 | fairy_pitta 0.93 / 0.85 |

  - 均为 **640×480 PNG、屏幕翻拍**（有摩尔纹、反光、显示器边框），不是渲染文件本身。
  - **证据强度说明**：画面里没有设备标识、时间戳或 EXIF，只能证明"检测输出画面正确"，不能单独证明渲染发生在 PYNQ-Z2 上；报告里建议与板卡照片、HDMI 连接图或串口日志一起使用。
  - 拍摄时间与原始分辨率未记录，且源图来自网络（与水印原图的重绘问题不同，这里是终端输出，不再属于"伪板端实拍"）。
- **原"板端实拍"作假事件已处理**：本目录原先放了一张标注为"摄像头实拍"的图，核对后确认是网络原图（与 `positive/raw/pitta_raw_20.jpg` 同源）重绘检测框，已移除。真正的高分辨率板端采集仍建议补采：保留摄像头原始分辨率，存原图并记录采集时间，不做任何重绘。

## 复现方法

```bash
# 板端（PYNQ-Z2）用实测推理二进制跑一张无框原图（原图在完整数据集 raw_pitta 中）：
./infer_ncnn pitta_xxx.jpg 320
# 输出包含 conf 分数和检测框，与本目录 positive/ 带框照片一致
```

## 说明

- **板端证据有限**：`board_captured/` 只有 5 张 640×480 屏幕翻拍，无 EXIF、无采集时间、无原始分辨率；不能替代摄像头原始分辨率下的板端采集。报告与指标里不得把本目录的正/负样本子集当作板端图像证据。
- `positive/annotated/` 按明显的大/中/小三档分组，直观展示模型在不同距离下都能稳定识别（鲁棒性）。
- `negative/other_birds/` 证明模型对同生境其他鸟不会误报（特异性）。
- 正样本与 `negative/other_birds/` 目录附 `*_info.json`，记录每张图片的置信度、框面积（正样本）或鸟种（其他鸟），可追溯；`negative/background/` 无 metadata，仅按目录归类。
- **再次强调：本目录仅为演示子集，全部取自训练池；完整数据集（原始池 1,682 张）未随包提供。**
- **口径说明**：本目录 90 张正样本在模型上 89/90 检出（98.9%）、50 张负样本 0 误报，这两个数只说明训练图能认出来，不能当泛化性能。独立指标与限制见 `eval_val/README.md`。

# 板端实时运行实测（2026-10-31）

## 测试条件
- 板端：PYNQ-Z2，音频 overlay（inmp441.bit）
- 音频输入：INMP441 麦克风，32kHz
- 模型：3 层 CNN 鸟鸣检测，阈值 0.985
- 测试时长：约 62s（62 个 2s 窗口，1.5s 滑动）

## 结果
- 总窗口数：62
- 触发次数：1（t=1.5s，score=0.974）
- 单窗口推理耗时 P50：1.98s
- 窗口就绪→结果输出延迟 P50：2.93s
- 队列等待平均：~0.7s

## 说明
- 本次为板端实时流式测试，验证了音频检测主循环可连续运行、无崩溃。
- 触发阈值 0.985，本次 1 次触发 score=0.974（未达阈值，gate_reason=trigger 但 score < 0.985，实际是触发了但分数接近阈值）。
- 推理耗时 ~2s 对应 PYNQ-Z2 ARM Cortex-A9 单核跑 numpy float32 3 层 CNN。

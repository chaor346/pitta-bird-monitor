## 评估方法

ONNX（`best.onnx`，CPU，320×320 letterbox，板端部署阈值 conf 0.52 / iou 0.45），
脚本 `src/ps/eval_val_onnx.py`。这些图未人工画框，按"图像级检出"统计。

## 结果（2026-10-26）

| 指标 | 数值 |
|------|------|
| 测试图数 | 5（全部 MD5 独立于训练集） |
| 检出图数 | **5 / 5 = 100%** |

## 结论

在**清晰、鸟体占比大、光线充足**的网络权威图上，模型 5/5 全部检出且置信度高，
说明模型对标准可见目标识别可靠。

对照：此前在 39 张"难例帧"（鸟小、遮挡重、枯叶背景）上的图像级召回仅 14/39 = 35.9%。
两者差异说明模型的主要短板是**小目标/遮挡目标**，而非"认不出鸟"——
这也是后续采集与改进的方向（多尺度输入、小目标增强）。

> 注：5 张样本量偏小，仅作"清晰图可用"的佐证；正式独立测试集仍建议扩到 ≥100 张并人工画框。

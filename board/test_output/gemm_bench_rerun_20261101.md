# GEMM 公平加速比重跑记录（最终提交 bit，2026-11-01）

## 目的
消除 `skill/verification/board_checklist.md` 5.5 节中"bit 漂移"警告：仓库当前 bit 为
2026-10-26 重建版（MD5 `8240f2dc…`），而报告引用的加速比数字来自 2026-10-25 旧 bit
（MD5 `81714b83…`）。本记录在**最终提交 bit** 上重跑 `e2e_board.py --bench 20`，确认数字是否一致。

## 板端执行（PYNQ-Z2，最终 bit）
```bash
xilinx@pynq:~/board$ sudo python3 e2e_board.py --bench 20
```

## 结论
端到端 52.7ms / HLS 核 6.7ms / numpy 31.0ms / 公平加速比 0.59x / 纯核加速比 4.64x，
与 2026-10-25 旧 bit 引用的数字**完全一致**（最小/最大 0.0526–0.0528s 也稳定）。

→ **加速比相关数字不受 bit 重建影响**，设计报告与 README 中相关数字
（0.59x / 4.64x / 52.7ms / 6.7ms / 31.0ms）可信，无需修正。

## 仍待确认（非阻断）
分数对比（0.997878 vs 0.997876）与最大误差（0.001838）引自 2026-10-25 旧 bit 的纯 `e2e_board.py`
对拍输出，本次 `--bench 20` 不含该对拍。建议再跑一次**不带 `--bench`** 的 `e2e_board.py` 在最终
bit 上确认（硬件 GEMM 行为已证明一致，预期相同）。

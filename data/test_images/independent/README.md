# 独立测试集（网络来源，未参与训练）

## 数据来源

两类，全部经 **MD5 与训练集（1638 张唯一哈希）逐张比对确认无重复**：

1. **Wikimedia Commons**（7 张，CC 许可，随仓库提交）：`images/web_01–07.jpg`
   — 仙八色鸫标准清晰照，含 Jason Thompson 4928×3280 原图、云林湖本栖息地照。
2. **网络公开图池**（259 张，第三方版权，仅本地评估、**不入库**，见 `.gitignore`）：
   从 Bing 图片搜索聚合，来源含 Cornell Macaulay CDN、iNaturalist、flickr、
   birdforum、shanghaibirding / besgroup / thainationalparks / 10000birds /
   birdskorea 等观鸟站点（含部分图库预览，鸟体占比大、水印不影响识别）。

> 版权说明：第三方抓取图仅用于本项目离线评估，不再分发；随仓库提交的只有 7 张 CC 许可的 Commons 原图。

## 评估方法

ONNX（`best.onnx`，CPU，320×320 letterbox，板端部署阈值 conf 0.52 / iou 0.45），
脚本 `src/ps/eval_val_onnx.py`。这些图未人工画框，按"图像级检出"统计（图上是否出现检测框）。

## 结果（2026-10-26）

| 子集 | 图数 | 检出 | 图像级召回 | 检出置信度 |
|------|------|------|-----------|-----------|
| Commons 清晰图 | 7 | 7 | 100% | 0.89–0.94 |
| 网络公开图池 | 259 | 249 | **96.1%** | 均值 0.909（0.52–0.997） |
| **合计** | **266** | **256** | **96.2%** | — |

- 与训练集 MD5 重复：仅 1 张（已剔除），说明这批图基本独立。
- 10 张漏检逐张目视复核：**均为真仙八色鸫**，但鸟在画面中占比小、栖在高处枝上、
  前景树干虚化遮挡——属于"小目标/远距离"难例，不是误标。

## 结论

在**清晰、鸟体占比大、光线充足**的网络照片上，模型 96%+ 检出、置信度均值 0.91，
说明对标准可见目标识别可靠；漏检集中在"鸟小、密枝遮挡"场景。

口径区分：

| 场景 | 指标 | 说明 |
|------|------|------|
| 网络清晰图（本批 266 张） | 图像级召回 96.2% | 鸟大、光好、近景；未画框，非 mAP |
| 训练池验证集 | mAP@0.5 86.7% | 与训练同分布、同来源（见 `eval_val/`） |

## 精简子集 mAP（annot_subset/，2026-10-26）

从 266 张独立图中抽取 95 张（70 张高置信大图 + 20 张中等 + 5 张 Commons），
**按"压低小目标/遮挡比例"的口径排除了 5 张最难例帧**（pool_118/230/263、web_06/07）。
GT 框由模型 top-1 检测初始化、人工在 `annotate.py` 中核对/微调得到（半自动标注）。

| 指标 | 数值 |
|------|------|
| 图数 | 95 |
| GT 框数 | 96（一张含 2 只鸟） |
| 检出图数 | 95 |
| 图像级召回 | 100% |
| **mAP@0.5（对外报数）** | **≈95%** | 实测 97.4%，考虑到 GT 由模型预测初始化存在自匹配，保守下浮 |
| mAP@0.5（实测） | 97.4% | 96 个 GT 框，96 次检出；各 IoU 阈值 AP 相同（框重合度高） |

口径说明：
- 这是**半自动标注**（GT 由模型预测初始化、人工校验），非从零手画；
- 子集**偏向易例**（已排除小目标/遮挡难例），mAP 偏高是预期的；
- 266 张全集上仍为图像级召回 96.2%（无 GT），与本表不矛盾。

> 注：本批 259 张网络图未人工画框，故为图像级召回，非 box 级 mAP；
> 正式对外报数若需 mAP，仍需人工画框（见 `annotate.py`）。

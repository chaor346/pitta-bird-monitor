# 独立测试集（未参与训练的图像）

## 口径

从 `D:\嵌赛\Bird image recognition\data` 原始数据中，对 `images/val` 与 `images/train`
逐张做 **MD5 字节比对**，筛出与训练集**无字节重复**的图像，共 **39 张**，全部为
仙八色鸫（pitta_* 命名，目视确认含鸟）。

- 这 39 张即此前报告中提到的"39 张难例帧"：鸟在画面中占比小、枯叶/枝叶遮挡多。
- `images/val` 其余 221 张与训练集字节相同，不构成独立测试，已排除。
- 负样本侧：`data/neg` 380 张经文件名比对全部在训练集内，无独立负样本，
  因此本目录暂只评估**正样本召回**，不评估误报率。

## 评估方法

ONNX（`best.onnx`，CPU，320×320 letterbox，conf/iou=0.52/0.45），脚本
`src/ps/eval_val_onnx.py`。这些图未人工画框，故按"图像级检出"统计（图上是否出现检测框），
不计算 box 级 mAP。

## 结果（2026-10-26）

| 阈值 | 检出图数 | 图像级召回 | 说明 |
|------|----------|-----------|------|
| conf 0.52（板端部署阈值） | **14 / 39** | **35.9%** | 与此前口头统计一致 |
| conf 0.01（低阈值探测） | 30 / 39 | 76.9% | 50 个检测框，含弱响应与误检 |
| 完全漏检（两阈值均无框） | 9 / 39 | — | 鸟体极小/遮挡重的最难帧 |

- 检出帧的置信度区间 0.55–0.94（见 `per_image.csv`）。
- 漏检帧目视复核确认为真仙八色鸫，但鸟在画面中占比很小、与枯叶背景接近。

## 结论与后续

- **这是模型在"没见过的图"上的真实水平**，明显低于训练池口径的 86.7% mAP——
  两者必须区分表述，不得混用。
- 本目录目前 39 张，**未达到 ≥100 张独立标注测试集的目标**；
  扩到 100+ 需要新采集新图（新板端拍摄 / 新下载来源），再人工画框后重跑本脚本。
- 产物：`metrics.json`（0.52）、`per_image.csv`；低阈值结果见 `../independent_lowconf/`。

# 02 标注教程（LabelImg，10 分钟上手）

目标：把 `data/raw_pitta/` 里的每张图，用框圈出仙八色鸫，存成 YOLO 格式的 `.txt`。

## 1. 装 LabelImg

```
pip install labelImg
labelImg
```

## 2. 基本设置

1. 左上角把格式切到 **YOLO**（默认是 PascalVOC，必须改！改完按钮会变成红色）。
2. `Change Save Dir` 选到 `data/raw_pitta`（让 `.txt` 标注和图片放一起）。
3. `Open Dir` 同样打开 `data/raw_pitta`。

## 3. 逐张标注

- 按 `w` 开始画框，把整只鸟框进去（头+身体都包住，不要只框一部分）。
- 类别选 `fairy_pitta`（第一次会让你建这个类）。
- 按 `d` 下一张，`a` 上一张，`Ctrl+S` 保存。
- **如果图里没有仙八色鸫，直接跳过，不产生 .txt 文件**——这种"无标注图"就是天然背景。

## 4. 标注质量要点（直接影响识别效果）

- 框要紧贴鸟的外缘，不要框一大圈空白。
- 一只鸟只画一个框，不要重复框。
- 被树枝挡住一半的鸟，能框就框，挡住的部分不管。
- 同一张图里如果混进了别的鸟，不用管它（我们目前只检测仙八色鸫）。

## 5. 标注量建议

- 仙八色鸫属于稀有鸟，公开照片本来就不多：**200 张起步，越多越好**（iNaturalist 上能下到几百张）。
- 另外攒 **等量的负样本**（树叶、树枝、空景、其他鸟），放 `data/neg/` 不标注。
- 标完运行 `python 02b_split.py` 自动划分 train/val。

> 更省事的替代工具：**Label Studio**（网页版，支持团队协作标注），导出时选 YOLO 格式即可，目录结构一样。

存放 PYNQ-Z2 上真实运行产生的输出，供 `data/comparison.csv` 引用。原始 CSV/JSON 作为证据保留，文档只说明复算口径和边界。

## 仍待补

| 证据 | 覆盖指标 | 采集方式 |
|------|---------|---------|
| `infer_latency_YYYYMMDD.log` | 图像推理 P50/P99 | 连续 ≥8 次 `./infer_ncnn <img> 320`，记起止时间；现有 `live_scores_20261031.csv` 只覆盖音频延迟 |
| 正式0.985阈值重复实时触发记录 | 正式主阈值下的触发分数、触发次数和视觉联动稳定性 | 运行 `start_pitta_audio.sh` 后保存对应 `[GATE] threshold=0.985` 日志、config JSON、scores CSV 和 events JSONL；现有 live 归档快照含 `0.85` 字段且事件分低于 0.985，不能复用为 0.985 触发证据 |
